This template helps you start developing with Vue 3 and TypeScript on the Rsbuild stack. The template uses Vue 3 `<script setup>` SFCs. See [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) for details.

By regularly running `pnpm run skills:update`, you can update your skills to be appropriate for AI-driven development.

_Just copy your `src` from Vite!_

Includes [vue-router](https://router.vuejs.org/) and [Pinia](https://pinia.vuejs.org/).

Linting and formatting are driven by a unified `pnpm run lint` pipeline using [Oxlint](https://oxc.rs/docs/guide/usage/linter.html) and [Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html). Oxlint applies lint fixes first, then Oxfmt formats the files.

Additionally, it includes [vue-tsc-api](https://github.com/escaton/vue-tsc-api/) instead of [vue-tsc](https://github.com/vuejs/language-tools/tree/master/packages/tsc), and [vue-devtools-rstack](https://github.com/OskarLebuda/vue-devtools-rstack#readme) instead of [vue-devtools](https://devtools.vuejs.org/), allowing for operation almost identical to the [Vite](https://github.com/logue/vite-vue3-ts-starter) version.

## Commands

The commands are designed to stay simple and CI-friendly.

| Command     | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| dev         | Start dev server.                                            |
| lint        | Run Oxlint fixes followed by Oxfmt formatting.               |
| lint:oxlint | Run Oxlint with automatic fixes.                             |
| lint:oxfmt  | Format the project with Oxfmt.                               |
| build       | Type-check and build for production.                         |
| build-only  | Build for production without type-checking.                  |
| type-check  | Check application types and Vue markup.                      |
| preview     | Run the program generated by the production build.           |
| analyze     | Analyze build artifacts.                                     |
| test        | Run tests with Rstest.                                       |
| test:watch  | Run tests in watch mode with Rstest.                         |
| clean       | Clear production build files.                                |
| clean:hard  | Clear production build files and build artifacts and caches. |
